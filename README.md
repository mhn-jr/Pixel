# Onella Nelora Lite — Mini App v1.2.0

## تازه در v1.2.0 (۲۰۲۶-۱۱-۰۹) — دیزاین = کپیِ دیدنیِ خود اپ Onella Nelora
- **همان نلورا، نه فقط الهام از آن:** کاربر وقتی مینی‌اپ را باز می‌کند باید بگوید «این دقیقاً همون نلوراست». همان توکن‌های دیزاین اپ اصلی (پس‌زمینهٔ #05070c، کارت #0d1320، نارنجی #f06a15)، همان چیدمان صفحهٔ چارت (گیج بالا، تب‌های بازار، نوار انتخاب نماد، تایم‌فریم بالای چارت)، همان مودال سرچ.
- **سرچ دقیقاً مثل اپ اصلی:** مودال تمام‌صفحه با عنوان «جستجو در کریپتو»، باکس بزرگ با placeholder مخصوص هر بازار («جستجوی ارز دیجیتال: BTC، SOL، PEPE ...»)، تب‌های بازار بالای مودال، ردیف‌ها با آیکون واقعی + نام + «BTC / USDT · کریپتو» + **ستارهٔ ⭐ برای واچ‌لیست** (در localStorage می‌ماند؛ تب «⭐ واچ‌لیست» هم در کاتولوگ هم در مودال هست).
- **کاتولوگ تب‌دار (مثل اپ اصلی):** به‌جای لیست بلند همهٔ بازارها، یک ردیف تب بازار (کریپتو، سهام، ETF، فارکس، کالا، ایران، شاخص، بورس، فرابورس + ⭐ واچ‌لیست) و شبکهٔ ۱۵ نماد همان بازار. بخش‌های ایران هم به تب‌های بازار اضافه شده‌اند.
- **بازار ETF (جدید):** ۱۵ ETF پرمعامله (SPY، QQQ، DIA، IWM، VTI، GLD، SLV، USO، TLT، SCHD، XLK، XLF، ARKK، VWO، EEM) از Yahoo.
- **گیج داده (همگرایی شواهد):** بالای صفحهٔ نماد، همان امتیازدهی اپ اصلی (js/01-13 — بدون MTF): EMA20 ±۲، EMA20/50 ±۲، EMA200 ±۱، MACD ±۱، RSI ±۱، ساختار ±۲، حجم ±۱، شکست ±۲؛ امتیاز ۰–۱۰۰ + گرایش صعودی/خنثی/نزولی + دلیل‌ها (مثل «+EMA20 +MACD»). تا کندل نیامده، گیج خالی است.
- **دو تب اصلی پایین صفحه:** 📊 چارت (کاتولوگ + نماد) و 📋 داشبورد. داشبورد سه بخش دارد: **۱) حرارت بازار** (سهم نمادهای مثبت + میانگین تغییر روزانهٔ هر بازار)، **۲) ۵ نماد صعودی + ۵ نماد نزولی** (از کل کاتولوگ، قابل‌لمس — با لمس هر ردیف نماد باز می‌شود)، **۳) اخبار مهم** با نماد مربوطه + **درصد تاثیر (تخمینی)** — بالا ۸۵٪ / متوسط ۶۰٪ / کم ۳۵٪ + ۱۰٪ اگر نماد در تیتر باشد (سقف ۹۵٪)؛ زیر خبرها نوشته شده که تخمین است. نرخ‌های ایران تغییر روزانه ندارند (live.json فقط قیمت لحظه‌ای دارد) پس در حرارت/صعودی‌نزولی نمی‌آیند — با یادداشت صادقانه.
- **چارت به سبک TradingView (پورت js/06 اپ اصلی):** اسکرول روی **محور قیمت** = زوم عمودی مقیاس قیمت؛ کشیدن روی محور قیمت = کش‌آمدن/فشرده‌شدن مقیاس؛ کشیدن عمودی روی چارت = جابه‌جایی قیمت؛ **دوبار لمس محور قیمت = مقیاس خودکار**؛ اسکرول روی چارت = زوم افقی حول نشانگر (کندل زیر ماوس ثابت می‌ماند)؛ دکمهٔ شناور **A** (مقیاس خودکار، وقتی مقیاس دستی است) و **⏭** (رفتن به آخرین کندل، وقتی عقب رفته‌ای). پینچ + کشیدن افقی + کراس‌هِر قبلی سر جایشان‌اند.
- **ابزارهای دستی روی چارت:** ردیف دکمه‌های فیبوناچی / حمایت‌مقاومت / خط روند / بولینگر / پیوت — همان `drawTools` اپ اصلی (حالا با `analyzeCS` واقعی: S/R از بولینگر و پیوت، ATR وایلدر، MACD). خوانش ابزار زیر چارت نشان داده می‌شود.
- **تایم‌فریم 1m و 3m (جدید):** کریپتو 1s · 1m · 3m · 5m · 15m · 30m · 1h · 4h · 1d · 1w · 1M؛ سهام/ETF/فارکس/کالا/شاخص 1m · 3m · 5m · 15m · 30m · 1h · 4h · 1d · 1w · 1M (سه‌ماهه از تجمیع ۳×۱ دقیقه ساخته می‌شود)؛ مفید 1m · 3m · 5m · 15m · 30m · 1h · 1d · 1w.
- **نوار انتخاب نماد (مثل اپ اصلی):** بالای صفحهٔ نماد، «▼ BTC/USDT» با آیکون + 🔍 — با لمسش مودال سرچ باز می‌شود و می‌توانی بدون برگشت، نماد عوض کنی.
- **راستی‌آزمایی:** هارنس vm — **۳۷/۳۷ قبول** (کاتولوگ تب‌دار، مودال سرچ + ستاره + واچ‌لیست، TF بالای چارت، 1s/1m/3m، ابزار fib + خوانش، گیج صعودی ۷۰/up و نزولی ۲۵/down، اسکرول محور قیمت + دوبارکلیک + زوم افقی، داشبورد با دادهٔ ساختگی، تب‌های پایین صفحه)؛ ورکر با شبکهٔ واقعی — **۸/۸ قبول** (`/yahoo-multi` با ۱۰ نماد واقعی + `/mofid kind=bulk` با فولاد واقعی).
- نصب v1.2.0: `app.js` + `index.html` + `asset-icons.js` را در GitHub جایگزین کن؛ **`worker.js` را حتماً دوباره در Cloudflare دیپلوی کن** — بدون آن، بخش Yahoo و بورس/فرابورس داشبورد کار نمی‌کند (کریپتو و خبر بدون دیپلوی هم کار می‌کنند؛ داشبورد خودش می‌گوید ورکر جدید لازم است).

## تازه در v1.1.0 (۲۰۲۶-۱۱-۰۹)
- **سرچ — خیلی مهم:** باکس سرچ استایل اپ اصلی (o-input) بالای کاتولوگ؛ **هر بازار ۱۵ نماد پیشنهادی** از قبل لود شده؛ موقع تایپ پیشنهاد زنده به‌تفکیک بازار می‌آید (فارسی هم می‌فهمد: «فولاد»، «طلا»، «اپل»، «بیت کوین»).
- **آیکون واقعی:** کریپتو از CDN رسمی (jsDelivr)، سهام از فاوآیکون گوگل، فارکس پرچم دو ارز، طلا/نقره بج Au/Ag؛ اگه آیکون نیامد بج حرفی می‌آید (هرگز جای خالی نیست). آیکون بازارها SVG خطی است.
- **بورس + فرابورس ایران (مفید):** دو بازار جدید، هر کدام ۱۵ نماد پرمعامله (فولاد، فملی، شستا، خودرو… / آریا، زاگرس، بپاس…). منبع **مفید** از ورکر (`/mofid` — ISIN از فهرست stockTickers خود مفید، فقط ردیف CommonStock با ISIN معتبر). قیمت = **آخرین قیمت پایانی** (تیک زنده ندارد) با تاریخ شمسی؛ کندل تا ۱ هفته‌ای. TSETMC از IP خارجی بلاک است و اینجا نمی‌آید؛ آگاه API عمومی ندارد.
- **چارت مثل اونلا:** زوم (دکمهٔ +/−، پینچ، اسکرول، کشیدن برای جابه‌جایی) + سوییچ نوع چارت (۶ نوع) + MA20/حجم + **تمام‌صفحه** (⛶؛ اگر مرورگر نخواست، حالت CSS).
- **تایم‌فریم بیشتر:** 5m · 15m · 30m · 1h · 4h · 1d · 1w · 1M (هر بازار به‌قدر توانش؛ مفید 4h و 1M ندارد).
- **زیر ۱ دقیقه برای کریپتو:** تایم‌فریم **1s** از Binance (کندل ۱ ثانیه‌ای) + OKX به‌عنوان fallback؛ اگر 1s برای نمادی نیامد، چارت قبلی می‌ماند و تایم‌فریم برمی‌گردد (هرگز جایگزینی خاموش).
- **زنده:** چارت و قیمت کریپتو زنده‌اند — اول WebSocket کندل Binance، اگر WS نرسید (از IP دیتاسنتر بلاک است) پولینگ REST (هر ۲ ثانیه برای 1s، هر ۱۰ ثانیه برای بقیه). بج «● زنده» (WS) یا «● به‌روزرسانی دوره‌ای» (پولینگ) نشان می‌دهد کدام حالت فعال است؛ با مخفی شدن صفحه، زنده قطع می‌شود.
- **پروب‌شده (۲۰۲۶-۱۱-۰۹):** مفید stockTickers ‏۴٬۴۱۵ نماد + کندل واقعی (فولاد ۴٬۵۴۰ ریال، ۴۰ کندل ۱ ساعته)؛ OKX ‏۱ ثانیه‌ای سالم؛ Nerkhsanj ‏۲۸ کلید (مثقال = `mesghal`، نه `mithqal` — کلید قبلی اشتباه بود و اصلاح شد)؛ WS بایننس از IP دیتاسنتر بلاک است (۱۰۰۶) — پولینگ جایگزینش شد.
- **راستی‌آزمایی:** هارنس vm — **۳۴/۳۴ قبول** (۸ بازار × ۱۵ نماد، سرچ فارسی/لاتین، آیکون‌ها، resolve + history مفید، OKX ‏۱ ثانیه‌ای، قیمت + کندل BTC، زوم، تمام‌صفحه، کندل 1s، زنده، رد 1s برای سهام، فولاد + کندل + قیمت پایانی).
- نصب v1.1.0: `app.js` + `index.html` + `asset-icons.js` را در GitHub جایگزین کن؛ **`worker.js` را حتماً دوباره در Cloudflare دیپلوی کن** — بدون آن، بورس/فرابورس و OKX کار نمی‌کنند (بقیهٔ نسخه بدون دیپلوی هم کار می‌کند).

## تازه در v1.0.2 (۲۰۲۶-۱۱-۰۹)
- **قیمت از ورکر:** وقتی گوشی/PC مستقیم به Binance/CoinGecko نمی‌رسد، قیمت و کندل کریپتو از ورکر Cloudflare می‌آید (مسیرهای تازهٔ `/binance` و `/coingecko`).
- **قیمت ایران — انتخاب دوم، نه جایگزین خودکار:** قیمت کریپتو از صرافی ایرانی (اکسیر → والکس → نوبیتکس) فقط با دکمهٔ «دلار | تومان» نشان داده می‌شود؛ پیش‌فرض همیشه دلار است. اگر دلار نیامد، باکس «در دسترس نیست» می‌شود و دکمهٔ «قیمت ایران (تومان)» هست تا کاربر خودش انتخاب کند. واحد: **تومان** (اکسیر و والکس تومان مستقیم‌اند؛ فقط نوبیتکس ریالی است و ÷۱۰ می‌شود). کندل ایرانی نیست — چارت همیشه کندل دلاری است.
- **رفع گیر «در حال بارگذاری»:** وقتی قیمت/کندل نمی‌رسد، تب‌های تحلیل/بنیادی/خبر «در دسترس نیست» می‌گیرند — دیگر برای همیشه روی لودینگ نمی‌مانند.
- **لوگوی واقعی:** هدر به‌جای ایموجی 🔥، آیکون شعلهٔ واقعی اپ را نشان می‌دهد (`logo.png` — همان آواتار ربات).
- **پروب‌شده (۲۰۲۶-۱۱-۰۹):** اکسیر `/v2/tickers` سالم (BTC ‏۲۰٬۳۲۰٬۷۰۰٬۰۰۰ تومان)؛ والکس `/v1/markets` سالم (BTC ‏۲۰٬۱۶۴٬۰۲۷٬۱۸۴ تومان)؛ هر دو در مرورگر CORS بلاک‌اند و فقط از ورکر می‌آیند. نوبیتکس از IP خارجی جواب نمی‌دهد (HTTP 000) — از PC خودت (IP ایران) باید پروب شود؛ ورکر خطای تمیز 502 می‌دهد. کندل UDF والکس استفاده نشد: قیمت‌های تاریخچه‌اش با قیمت زنده نمی‌خواند (پروب ۲۰۲۶-۱۱-۰۹).
- **راستی‌آزمایی:** هارنس vm — ۱۴/۱۴ قبول (قیمت دلاری از ورکر، دکمهٔ تومان، چارت ۱٬۴۴۸ عملیات Canvas، بدون ورکر «نیست»)؛ ورکر با شبکهٔ واقعی — ۸/۸ قبول.
- نصب v1.0.2: `app.js` + `worker.js` + `index.html` را جایگزین کن، `logo.png` را اضافه کن، ورکر را دوباره دیپلوی کن، `PROXY_URL` را در `app.js` بگذار.

# Onella Nelora — Mini App v1.0.1 (قبلی)

مینی‌اپ تلگرامِ ربات Onella Nelora — صفحهٔ استاتیک (HTML/CSS/JS)، بدون سرور، بدون کلید، بدون دیتابیس.
فقط فایل‌های همین پوشه روی سایت می‌روند؛ **کل پروژهٔ اونلا روی سایت نمی‌رود.**

## چی دارد
- **کاتولوگ** — ۹ بازار (کریپتو، سهام، ETF، فارکس، کالا، ایران، شاخص، بورس، فرابورس) + واچ‌لیست ستاره‌دار
- **داشبورد** — حرارت بازار + ۵ صعودی/۵ نزولی + اخبار مهم با درصد تاثیر (تخمینی)
- **قیمت** — کارت قیمت نماد (Binance / Yahoo / Frankfurter / Nerkhsanj)
- **چارت** — **چارت بومی خود اونلا** (همان `01-08c-chart-style.js` + `01-09-native-chart.js` اپ، فقط UI اپ حذف شده):
  کندل/توخالی/بار/هیکین‌آشی/خطی/ناحیه‌ای، حجم، MA20، محور قیمت گرد، محور زمان هوشمند،
  خط قیمت زنده + شمارش معکوس بسته‌شدن کندل، کراس‌هِر با لمس/ماوس — تایم‌فریم 15m/1h/4h/1d
- **تحلیل** — همان موتور محلی ربات (`analysis.js`): روند، RSI، بولینگر، حمایت/مقاومت، ATR، حجم —
  بدون سیگنال، بدون پیش‌بینی، بدون توصیهٔ معامله؛ نوع روش در پیام ذکر نمی‌شود
- **بنیادی** — کریپتو از CoinGecko، سهام از Yahoo quote (با پروکسی)
- **خبر** — همان RSS ربات (Google News + CoinDesk) با برچسب نماد و میزان تاثیر (تخمینی)

## نصب — ۳ مرحله

### ۱) هاست کردن صفحه (GitHub Pages — رایگان)
1. در GitHub یک ریپوی **عمومی** (Public) بساز، مثلاً `onella-miniapp`
2. همهٔ فایل‌های همین پوشه را داخلش آپلود کن (به‌جز `worker.js` — آن جدا می‌رود)
3. Settings → Pages → Branch: `main` → Save
4. آدرس می‌شود: `https://<نام‌کاربری>.github.io/onella-miniapp/`

> جایگزین: Cloudflare Pages — همان فایل‌ها را آنجا هم می‌توانی بگذاری.

### ۲) پروکسی (اختیاری، ولی برای سهام/خبر/نرخ ایران لازم است)
بدون پروکسی فقط این‌ها کار می‌کنند: **کریپتو** (قیمت + چارت + تحلیل + بنیادی، اگر گوشی/PC مستقیم به Binance/CoinGecko برسد) و **قیمت فارکس** (Frankfurter).
خبر، سهام، کالا، شاخص، نرخ ایران و **قیمت ایرانی کریپتو** پروکسی می‌خواهند و بدون آن «در دسترس نیست» می‌گیرند — هرگز عدد ساختگی نمی‌آید.
از v1.0.2، اگر مستقیم نمی‌رسد، کریپتو هم از پروکسی می‌آید — پس پروکسی عملاً برای همهٔ بازارها لازم است.

1. در [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → **Worker** بساز
2. محتوای `worker.js` را جایگزین کد پیش‌فرض کن → Deploy
3. آدرس ورکر را کپی کن، مثلاً `https://onella-mini-proxy.<نام>.workers.dev`
4. در `app.js` خط اول را عوض کن:
   ```js
   var PROXY_URL = 'https://onella-mini-proxy.<نام>.workers.dev';
   ```
5. `app.js` را دوباره در ریپو آپلود کن

پلن رایگان ورکر: ۱۰۰٬۰۰۰ درخواست در روز — برای مینی‌اپ کافی است.
ورکر فقط به ۹ هاست مجاز درخواست می‌فرستد (Yahoo، Google News، CoinDesk، Nerkhsanj، Binance vision، CoinGecko، Exir، Wallex، Nobitex)؛
هاست دیگر را با 403 رد می‌کند — پروکسی باز نیست.

### ۳) وصل کردن به ربات (BotFather)
1. در تلگرام به **@BotFather** برو
2. دستور `/setmenubutton` را بفرست
3. ربات را انتخاب کن: **@Onella_Nelora_Bot**
4. آدرس صفحه را بفرست: `https://<نام‌کاربری>.github.io/onella-miniapp/`
5. دکمهٔ منو را بزن — مینی‌اپ داخل تلگرام باز می‌شود

## تست محلی (قبل از آپلود)
```bash
python -m http.server 8000
```
بعد در مرورگر: `http://localhost:8000/` — کاتولوگ و BTC را بزن؛
چارت و تحلیل و بنیادی کریپتو بدون پروکسی هم کار می‌کنند.
(برای سهام/خبر باید `PROXY_URL` را بگذاری.)
